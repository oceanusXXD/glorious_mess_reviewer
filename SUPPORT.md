# Support

Use the fastest path that matches the problem.

| Need | Best Path |
| --- | --- |
| Local setup or CLI usage | Run `glorious_mess_reviewer doctor`, then open a bug report with the JSON output |
| API route behavior | Include route, request payload shape, response status, and sanitized response body |
| Venue profile or rubric design | Open a feature request with the intended screening desk and desired tradeoffs |
| Security or sensitive data | Follow `SECURITY.md`; do not post private payloads publicly |
| General usage | Start with `README.md`, `docs/api.md`, and `docs/configuration.md` |

Please keep reports reproducible and sanitized.
